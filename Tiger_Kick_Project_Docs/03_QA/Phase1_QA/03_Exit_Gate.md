## 1. เงื่อนไข DoD (ต้องครบทุกข้อ)
- [ ] ผู้เล่น 4–8 คนวิ่งพร้อมกันได้ และทุกเครื่องเห็นตำแหน่งตรงกัน
- [ ] Sprint ทำงานและรู้สึกต่างจากเดินปกติ
- [ ] ไม่มีอาการ teleport/กระตุกรุนแรงในเน็ตเวิร์กปกติ

## 2. เงื่อนไขคุณภาพ (Quality Gate)
- [ ] Unit / Integration / Manual / Playtest ผ่านตามแผน
- [ ] Regression ผ่าน (ต้องรัน **ก่อน** ปิด DoD)
- [ ] ไม่มีบั๊ก **S0 (Crash)** ค้าง
