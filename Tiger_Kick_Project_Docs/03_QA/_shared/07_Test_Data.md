# Test Data — Tiger Kick

ชุดข้อมูลมาตรฐานสำหรับการทดสอบ เพื่อให้ทำซ้ำได้เหมือนเดิมทุกครั้ง (reproducible)
อ้างอิงชุดข้อมูลเหล่านี้ในทุก Test Case แทนการสุ่มค่าเอง

## 1. รูปแบบผู้เล่น (Player Setup)
| รหัส | บทบาทเริ่มต้น | หมายเหตุ |
|---|---|---|
| Host | ตัวจัดการ server (อาจเล่นด้วย) | เป็นผู้ตัดสิน (authority) |
| Peer 1–7 | ผู้เล่นทั่วไป | ใช้เท่าที่จำนวนผู้เล่นต้องการ |

## 2. จำนวนผู้เล่นมาตรฐาน
2, 4, 6, 8 คน (ใช้ 2 สำหรับ smoke, 8 สำหรับ stress/benchmark)

## 3. โปรไฟล์เน็ตเวิร์ก (Network Profiles)
| โปรไฟล์ | Latency | Packet Loss | ใช้กับ |
|---|---|---|---|
| N0 (ideal) | 0 ms | 0% | smoke / dev |
| N1 (good) | 50 ms | 0% | baseline |
| N2 (avg) | 150 ms | 5% | chaos ระดับกลาง |
| N3 (bad) | 300 ms | 10% | chaos หนัก |
| N4 (worst) | 300 ms+ | 20% | recover test |
