# Exit Gate — Phase 0 — Setup & Networking Foundation

ประตูอนุมัติก่อนขึ้นเฟสถัดไป (อ้างอิง Definition of Done ใน GDD ของเฟสนี้โดยตรง)

## 1. เงื่อนไข DoD (ต้องครบทุกข้อ)
- [ ] clone repo แล้วเปิดใน Godot ได้ทันทีโดยไม่มี error
- [ ] เปิดสองอินสแตนซ์ กด Host และ Join แล้วเชื่อมต่อกันสำเร็จ
- [ ] มี log/ข้อความยืนยันว่า peer เข้ามาแล้ว

## 2. เงื่อนไขคุณภาพ (Quality Gate)
- [ ] Unit / Integration / Manual / Playtest ผ่านตามแผน
- [ ] Regression ผ่าน (ต้องรัน **ก่อน** ปิด DoD)
- [ ] ไม่มีบั๊ก **S0 (Crash)** ค้าง
- [ ] ไม่มีบั๊ก **S1 (Desync)** ค้าง
- [ ] บั๊ก S2 ที่ค้างมีแผนจัดการชัดเจน
