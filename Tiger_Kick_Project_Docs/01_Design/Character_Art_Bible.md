## 1. Art Direction (โทนรวม)  — 🔒 LOCKED โดยคุณ (2026-07-04)
- สไตล์: ☑ **Stylized / Toon + Low-poly** (cel-shaded, โพลีต่ำ, ตั้งใจให้รันบน integrated GPU ได้)
- อารมณ์ที่ต้องการ: **ฮา · น่ารัก · สีสด · การ์ตูน** (ตัวเสือแฝงความ "ดุนิด ๆ")
- อ้างอิงหลัก (mood board): **MECCHA CHAMELEON** — cartoon low-poly, ตัวละครทรงเรียบ, ฉากสีสด, แสงนุ่ม
- เหตุผลเลือกสไตล์นี้: เอื้อมถึงได้จริงด้วยทีม 2 คน (บาร์เทคนิคต่ำ) + คุณภาพที่เห็นมาจาก **art direction + lighting/post-processing** ไม่ใช่จำนวนโพลีกอน

## 2. Color Palette
- ทิศทาง: โทนสีสด ๆ แบบการ์ตูน (saturated) บนฉากที่คุมโทนกลาง เพื่อให้ตัวละครเด่น
- สีหลัก: `____`   สีรอง: `____`   สีเน้น (accent): `____`  *(← ค่าเฉพาะ hex ยังรอคุณเลือก)*
- **สีของ "เสือ" ต้องเด่นและอ่านง่ายในทุกฉาก** (กันสับสนว่าใครเป็นเสือ) — เสนอ: ส้ม-ดำลายเสือ ที่ค่า saturation สูงกว่าทุกตัวในสนาม
- **ข้อบังคับด้าน readability:** สีเสือต้องไม่ชนกับสีที่ผู้เล่นทาเองได้ (ดู §4) → กันสีโทนส้มแรง ๆ ออกจาก palette ที่ผู้เล่นเลือกได้ หรือใส่ Tiger Indicator ที่ไม่พึ่งสีอย่างเดียว (ดู §5)

## 3. Tiger (ตัวเสือ)  — 🔒 LOCKED + มี visual reference (2026-07-04)
- สไตล์: **low-poly toon เสือ** ตามอ้างอิง MECCHA CHAMELEON + **ภาพ reference ที่คุณให้ (CHARACTER STYLE เสือ)**
- **Silhouette / สัดส่วน (ล็อกตาม reference):**
  - **หัวโต ตัวเล็ก** — head-to-body ratio ประมาณ chibi (หัวใหญ่ ~40–50% ของความสูง)
  - **ทรงป้อมกลม อ้วนน่ารัก** ยืนสองขา (bipedal) ขา/แขนสั้น ป้อม
  - **หูกลมสองข้าง + หางลายเสือ + เขี้ยวเล็กโผล่**
  - **ขนาด: สูง ~2.0m — ใหญ่/สูงกว่าโมเดลผู้เล่น (1.2–1.4m) อย่างชัดเจน** → เสือคือ silhouette ที่ใหญ่+มีหู+ลาย ส่วนผู้เล่นเล็ก+เรียบ แยกจากเงาได้ทันที
- **สี (ตายตัว ผู้เล่นแก้ไม่ได้):** ตัวส้ม + **ลายดำ** + **พุง/ปาก/รอบตา/มือ-เท้าสีครีม** ตา/จมูกเข้ม หน้าตาสดใส
- **มาร์กกิ้งเด่น:** **รอยเท้าแมว (paw print) สีเข้มกลางพุงครีม** — เป็น signature ของตัวเสือ
- **Turnaround ที่ต้องมี (ตาม reference sheet):** Front · 3/4 · Side · Back — ท่ายืน T/A-pose สำหรับ rig
- **Topology / โพลีบัดเจ็ต:** low-poly **~1K–2K tris** clean quad — พร้อม rig สำหรับ Animation Set §7
- บุคลิก: การ์ตูน ยิ้มแฉ่งน่ารัก (เป็นเป้าให้เตะ แต่ไล่จับแล้วลุ้น)
- **สีตัวเสือเป็นสีตายตัว** — เพื่อให้ "ใครเป็นเสือ" อ่านง่ายเสมอ ตรงข้ามกับผู้เล่นที่แต่งเองได้ (§4)

> 📎 **ไฟล์ reference:** เซฟ character sheet (turnaround 6 มุม) ที่คุณให้ไว้ที่ `01_Design/refs/tiger_style_ref.png`
> ยึดเป็นมาตรฐานหน้าตา/สัดส่วน/มาร์กกิ้งของเสือ — `designer`/`polish-agent` เปิดดูก่อนทำโมเดลจริง
> ✅ **เสือขาวใน sheet = palette variant เฉย ๆ** (2026-07-04) — เป็นแค่ตัวอย่างโทนสี ไม่ใช่สกินเล่นได้/ไม่ใช่บทบาทใหม่ ไม่กระทบ Tiger Indicator · **เสือมาตรฐานในเกม = ส้ม+ลายดำ+พุงครีม**

## 4. Player (ผู้เล่นทั่วไป)  — 🔒 LOCKED + มี character sheet (2026-07-04)
- **โมเดลฐาน:** low-poly toon ทรงเรียบ กลมป้อม น่ารัก **สีพื้น/ขาวเปล่า = "ผ้าใบ"** (เหมือน MECCHA CHAMELEON ที่เริ่มจากตัวเปล่า) — ไม่มีหู/ลาย เพื่อแยกจากเสือ
- **ขนาด:** สูง **1.2–1.4m** (เล็กกว่าเสือ 2.0m ชัดเจน)
- **โพลีบัดเจ็ต / ชิดดิ้ง:** low-poly ~1K–2K tris · Toon Shader + Rim Light (เข้าชุดกับเสือ §9)
- **Turnaround ที่ต้องมี:** Front · Side · Back · 3/4
- **ผู้เล่นวาด/ใส่สีตัวเองได้ — COSMETIC ล้วน ทำที่ Lobby ก่อนเริ่มเกม** (รายละเอียด §4B)
- **ไม่ใช่กลไกพรางตัว** — การทาสีไม่มีผลต่อ gameplay (ไม่ช่วยหลบเสือ) เพราะแก่นเกมคือ "แอบเข้าไปเตะแล้วหนี" ไม่ใช่ซ่อนหา
- ต้องแยกจากเสือชัดในระยะไกล/แสงน้อย → **ล็อกลาย+สีเฉพาะของเสือไว้ ห้ามผู้เล่นเลียนแบบ**

## 4B. Lobby Customization (ระบบแต่งตัว)  — 🔒 LOCKED ตาม sheet (2026-07-04)
> โยงกับ Round Flow §Lobby ใน TDD — เป็นสถานะ Lobby ก่อน Random Tiger · ทั้งหมด **Cosmetic Only** ไม่กระทบ gameplay
- **ที่ไหน/เมื่อไหร่:** หน้า Lobby ก่อนแมตช์เท่านั้น (ระหว่างแมตช์แก้ไม่ได้ → กัน desync + กันสับสน)
- **(a) สีพื้นฐาน (8 สี):** ขาว · ครีม · เหลือง · ชมพู · ฟ้า · เขียว · ม่วง · ดำ
- **(b) ลวดลาย/เขียนบนตัว (decal):** เช่น หน้ายิ้ม/ดาว/กากบาท/ก้นหอย/มงกุฎ/"สู้ๆ"/สายฟ้า/"KICK ME!" — แปะได้
- **(c) แต่งตัว (accessory 4 หมวด):** หมวก (แคป/บีนนี่/บักเก็ต/หูฟัง) · กระเป๋า/เป้ · ผ้าพันคอ/ผ้า · แว่นตา
- **ซิงก์:** ค่าแต่งตัวเป็นข้อมูลผู้เล่น ส่งครั้งเดียวตอนเข้าห้อง/กด Ready แล้ว broadcast (ไม่ใช่ real-time paint → เบา network)
- **ขอบเขต Phase:** ไม่แตะ Phase 0–2 (พิสูจน์ความสนุกก่อน) — วางไว้ **Phase 4 (Polish) ขั้นต่ำ / เต็มก่อน Ship**
- **guardrail readability:** บังคับ contrast ขั้นต่ำ กันทาจนกลืนฉาก · **ล็อก palette+ลายเสือ** กันปลอมเป็นเสือ
- **In-Game usage (ตาม sheet):** ผู้เล่นอ่านออกจาก **สี+รูปทรง** · โดนเตะแล้วมี knockback/ล้ม · ใช้สี/ของแต่งตัวบ่งบอกตัวตน (แยกว่าใครเป็นใคร)

## 5. Tiger Indicator (สำคัญที่สุด)
"ใครเป็นเสือคนใหม่" ต้องรู้ได้ทันทีทุกเครื่อง (โยงกับ Tag Sequence + Round Flow)
- วิธีบ่งชี้: ☐ สีตัว  ☐ ขนาด  ☐ เอฟเฟกต์รอบตัว  ☐ ไอคอนเหนือหัว  ☐ อื่น: `____`
- ต้องชัดทั้งมุม First Person (เสือมองตัวเอง/มือ) และ Third Person (คนอื่นมอง)
- **⚠️ ผลกระทบจากระบบทาสีผู้เล่น (§4B):** เพราะผู้เล่นเลือกสีเองได้ → **ห้ามพึ่ง "สีตัว" อย่างเดียว** เป็นตัวชี้เสือ ควรใช้หลายชั้นซ้อนกัน เช่น *ร่างเสือเป็นโมเดลคนละตัว + เอฟเฟกต์รอบตัว/ไอคอนเหนือหัว* เพื่อกันผู้เล่นทาสีปลอมเป็นเสือ

## 6. Silhouette & Readability

## 7. Animation Set ที่ต้องมี (ผูกกับ TDD §8 + Phase 4)
Idle · Walk · Run/Sprint · **Jump** · Kick · **Tag Sequence: Grab → Throw → Transform (เสือ↔คน)** · Caught/โดนเตะ (ล้ม)
- งบเวลา Tag Sequence ตาม GDD: รวม ≤ 1.5 วินาที (Grab 0.2–0.3 / Throw 0.3–0.5 / Transform 0.5–0.7)
- **ใช้ชุดแอนิเมชันร่วมกัน** ระหว่างเสือกับผู้เล่น (rig เดียวกันได้ยิ่งดี) — ตัวหลักที่ sheet ผู้เล่นเน้น: วิ่ง · กระโดด · เตะ · โดนเตะ/ล้ม
